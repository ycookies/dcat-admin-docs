# AI 编码技能（Skills）

> dcat-plus-admin 从 v3.x 起随 Composer 包分发一套 **AI 编码技能文档**（`.claude/skills/`），让 ZCode、Claude Code 等支持 Skills 机制的 AI 编码工具在开发后台时"懂这个框架"——按当前版本的 API 生成代码、避开已知坑，而不是凭训练数据猜一个过时写法。

## 一、它是什么

包内目录 `vendor/dcat-plus/laravel-admin/.claude/skills/`：

```
.claude/skills/
├── SKILL.md          # 技能入口：安装、CRUD、表单/Grid/API/扩展开发全流程速查
└── references/       # 9 个专项参考（与包源码同步维护）
    ├── form-fields.md           # 表单字段完整参考（含表格模式结构化表头等新能力）
    ├── grid-system.md           # 数据表格
    ├── widgets.md               # 页面组件（含 ContentFormat 富文本识别渲染）
    ├── action-system.md         # 动作与表单响应
    ├── api-development.md       # API / 接口文档开发
    ├── database-schema.md       # 数据库结构
    ├── extension-development.md # 扩展包开发
    ├── extension-workflow.md    # 扩展开发工作流
    └── infrastructure.md        # 基础设施（含资源别名、前端集成要点）
```

这些文档**随功能提交同步更新**（版本发布时与代码一起进入 tag），描述的就是你当前安装版本的真实行为，比外部教程和模型记忆可靠。

## 二、怎么用

### 1. AI 工具自动加载（推荐）

ZCode / Claude Code 等工具的项目级 skills 机制会识别 `.claude/skills/`。把包内技能链接或复制到你的项目后，AI 自动获得框架知识：

```bash
# 在你的 Laravel 项目根目录执行（二选一）
# 软链（跟随包升级）：
ln -s vendor/dcat-plus/laravel-admin/.claude/skills .claude/skills
# 或复制（固化当前版本）：
cp -R vendor/dcat-plus/laravel-admin/.claude/skills .claude/skills
```

之后直接对 AI 提需求即可，无需贴文档：

```
帮我写一个活动管理的后台：表格带筛选，表单里用 table 字段编辑报名项目
（单价列 120px 宽、help 提示价格规则），详情页 content 字段要能预览
Markdown 和富文本两种内容。
```

AI 会按参考文档生成：`hasMany/table` 结构化表头写法（`columnWidth()`、`->help()` 上收表头）、`$show->field('content')->richText()` 等当前版本的正确用法。

### 2. 人工查阅

文档本身就是高质量的速查手册——写代码拿不准方法签名、字段配置、资源别名时，直接搜 `references/` 对应文件。

## 三、文档里沉淀的关键约定（速览）

参考文档除了 API，还记录了大量**只有读源码才知道的坑**，例如：

| 约定 / 坑 | 说明 |
|---|---|
| JS 函数必须包装 | 所有需传 JS 函数的配置（`onSelect`/`setup` 等）必须用 `Dcat\Admin\Support\JavaScript::make()` 包装，写字符串会崩溃 |
| `Dcat.init` 不监听动态 DOM | 动态新增行/元素里的 select、日期选择等组件必须手动初始化（jquery-initialize 无 MutationObserver 重放） |
| 吸顶导航栏基准 | 高 60px、`z-index: 997`；悬浮内容需低于此值（UEditor 容器默认 990）；滚动定位已被全局 `scroll-padding-top` 补偿 |
| 原生 select 无箭头 | AdminLTE 设置了 `appearance:none`，未挂 select2 的原生 select 需补 `appearance: menulist-button` 兜底 |
| 全局 CSS 挂载点 | `partials/navbar.blade.php` 的 `<style>` 块全后台生效，跨页面样式优先放这里 |
| layui-layer 移动端 | ≤768px 已全局适配为全宽留边显示，无需单弹层处理 |

完整内容见 `references/infrastructure.md` 的「前端集成要点」与各专项文件。

## 四、维护约定（贡献者必读）

- **功能更新必须同步文档**：对包做功能增删改时，同步更新 `.claude/skills/references/` 对应文件（表单 → `form-fields.md`，组件 → `widgets.md`，资源/层级 → `infrastructure.md`，以此类推），随功能一起提交；
- 写法保持既有格式：密集表格 + 可运行代码示例 + ⚠ 坑警告；
- 2.x 分支的 skills 与 3.x 全量同步，更新时一并回移。
