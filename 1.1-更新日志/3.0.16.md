## 修复

### 1. 弹窗内无法再打开弹窗的第六死因：筛选面板拦截冒泡

**背景**：在 dcatplus-demo 实测嵌套弹窗（`with-border` 页新增"嵌套弹窗测试"列：外层异步表格弹窗 → 行内再开内层表单弹窗）时发现：v3.0.15 的五死因补丁全部生效（手动 `.modal('show')` 一切正常），但**点弹窗内的"再开弹窗"按钮毫无反应**——按钮点击根本打不开内层。

**根因**（逐层冒泡追踪定位）：`Grid\Tools\FilterButton`（表格筛选滑出面板）为避免"点击弹窗内容误关筛选面板"，注册了：

```js
$('.wrapper').on('click', '.modal', function (e) {
    e.cancelBubble = true;
    e.stopPropagation();   // ← 无差别掐断 .modal 内所有点击的冒泡
});
```

而弹窗按钮（`[data-toggle="modal"]`）依赖 **Bootstrap data-api 的 document 级委托**——冒泡被掐断在 `.wrapper` 层，document 永远收不到点击，**弹窗内所有打开弹窗的按钮全部失灵**。这是 dcat 的历史老坑，与五死因叠加后构成"弹窗内开弹窗"的第六个死因。

**修复**：删掉无差别拦截，把"弹窗内排除"逻辑收进关闭筛选面板自己的判断：

```js
$(document).on('click', '.wrapper', function (e) {
    if (slider && slider.close && !$(e.target).closest('.modal').length) {
        slider.close();
    }
});
```

**实测结果**（嵌套全链路）：

| 验证点 | 结果 |
|---|---|
| 弹窗内点"弹窗编辑"打开内层 | ✓（z-index 1080 / backdrop 1079 按层递增） |
| 内层移到 body 脱离外层 stacking context、自动去 fade | ✓ |
| 点内层关闭按钮只关内层，外层不受影响 | ✓ |
| 关内层后 `modal-open` 保持、backdrop 对齐 | ✓ |
| 关外层后完全收尾（无残留弹窗/遮罩/滚动锁） | ✓ |

> 二次开发警示（已写入 skills）：弹窗内注册 click 委托时**严禁对 `.modal` 内点击无差别 `stopPropagation()`**——会掐断 data-api 让弹窗内按钮失灵。
