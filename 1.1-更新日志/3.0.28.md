## 一、Show 详情页体系增强（本轮核心）

### 1. tab 页签分组展现

`$show->tab()` 链式分组：`field()`/`relation()`/`row()` 均可归入页签，nav-tabs 原生切换；tab 之外的字段仍平铺在上方，工具栏不受影响。

```php
$show->tab('基本信息', function ($show) {
    $show->field('name', '名称');
    $show->field('email', '邮箱');
})->tab('订单记录', function ($show) {
    $show->relation('orders');
});
```

页签带 **hash 记忆**：点击写入 URL hash（如 `#tab-1`），刷新/分享链接按 hash 恢复激活页签。

### 2. 详情字段默认宽度 8→10

`field` 默认栅格宽度从 8 调整为 10——长标题、富文本等内容的展示更从容，短字段仍可用 `width()` 自定。

### 3. field-type-* 样式钩子

每个字段行自动注入 `field-type-{type}` 样式类（展示器自动记录字段类型，扩展字段取方法名，Str::kebab 归一），可按字段类型精准定制样式，无需逐个加 class。

### 4. 修复

- **html 字段内图片超宽自适应**：详情 html 字段中的大图超出容器时自动缩到 100% 宽（不超宽保持原尺寸）；
- **json 字段 PHP8 兼容**：值含数组/对象时不再报错——递归下钻转义（`array_walk_recursive`），非标量值先 JSON 编码再转义；
- 详情容器加 `page-detail-show` 样式钩子。

## 二、StepProgress 步骤条 Widget（新增）

向导式步骤进度条，横向，三风格可选：

```php
use Dcat\Admin\Widgets\StepProgress;

StepProgress::make([
    ['num' => '01', 'title' => '提交申请', 'description' => '2026-11-20 09:30'],
    ['num' => '02', 'title' => '审核中',   'description' => '等待财务复核'],
    ['num' => '03', 'title' => '已完成'],
], 2)->style('arrow');
```

- **三风格**：`dot` 圆点连线（默认）/ `check` 完成步打勾 / `arrow` 箭头分段；
- **current 1-based**：之前 done、当前高亮、之后 todo；
- **序号数据驱动原样展示**（`num` 传什么显示什么，缺省回退位置序号）；
- `description` 悬浮 tips 提示（tips/data-title 约定）；
- arrow 风格细节：完成段渐变+随形投影、当前段浅主题色底+序号徽标化、段间分界加宽防粘连；
- 颜色自动取后台主题色（CSS 变量注入），深色模式适配。
