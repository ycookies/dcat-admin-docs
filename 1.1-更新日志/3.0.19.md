## 重大重构

### 1. BS4 modal 全面迁移 layui-layer（方案 A 治本）

`Widgets\Modal` 内部渲染重写为 **layui-layer 承载**（统一走 DialogForm 成熟通道），类签名完全冻结、现有代码零改动。Bootstrap 4 modal 官方不支持多实例叠加，嵌套弹窗的 **z-index 固定 / fade 回调卡死 / dismiss 冒泡 / onShow 误触 / stacking context / FilterButton 拦截** 六大死因自此根除——不再需要补丁堆叠。

- 弹窗内异步表格：分页、排序、搜索、行删除、批量删除全部**弹窗内完成，不再整页跳转**；
- 弹窗创建（`enableDialogCreate`）、快捷编辑在弹窗内保存后不再跳转；
- 高度自适应：内容变化自动跟随、垂直居中、超长内容 80vh 内滚动、滚动条细化；
- 尺寸支持保留：`sm()/lg()/xl()` 映射 layer 宽高档位；
- 如遇兼容问题可在 `config/admin.php` 切回旧驱动：`'layout' => ['modal_driver' => 'bootstrap']`。

```php
// 用法完全不变
$modal = Modal::make()->lg()->title('编辑')->body(new UserForm(['id' => 1]));
```

### 2. 异步表单保存行为：按 JsonResponse 指令分发

弹窗表单（Modal + LazyRenderable）提交成功后，**完整尊重服务端返回的后续指令**，与整页表单语义对齐：

| 服务端写法 | 弹窗内行为 |
|---|---|
| `->success('保存成功')` | toast 提示 + 关闭弹窗，**不刷新** |
| `->success('保存成功')->refresh()` | toast + **整页重载**（refresh 原始语义） |
| `->success('ok')->download($url)` | toast + **新窗口下载** |
| `->location($url)` / `->redirect($url)` | toast + 整页跳转（`location(null)` = 重载） |
| `->script($js)` | toast + 执行 JS |
| `->error('失败')` | 错误提示，**弹窗保留**供修改重试 |

```php
public function handle(array $input)
{
    // 导出场景：保存配置后直接触发下载
    return $this->response()->success('已生成')->download('export/report.zip');
}
```

### 3. 提示形态全量支持：alert / detail / timeout / info / warning

弹窗表单的提示展示与整页表单完全一致——此前 `alert()` 等在弹窗内静默降级为普通 toast，现已修复：

```php
return $this->response()
    ->success('操作完成')      // 也支持 info()/warning()/error() 四种类型
    ->alert()                  // SweetAlert 居中弹窗（替代右上角 toast）
    ->detail('这里是详细说明')  // alert 正文
    ->timeout(5);              // toast 时长（秒）
```

## 安全升级

### 4. jQuery 3.4.1 → 3.7.1（CVE-2020-11022 / CVE-2020-11023）

修复 `$.html()` 处理不可信输入的 XSS 漏洞。`vendors.min.js` 由 packer 混淆编码重组为**明文分段**（jQuery 3.7.1 + Popper + Bootstrap 4 JS + Hammer 2.0.8 + perfect-scrollbar 1.4.0），后续可维护性大幅提升；顺带清理了两个零引用的历史遗留库（screenfull、es6-promise）。

> **升级注意**：本版本静态资源有变更，升级后需执行 `php artisan admin:publish --force` 并强制刷新浏览器（Ctrl/Cmd+Shift+R）。

## 修复

### 5. select2 下拉在弹窗内无法选择

select2 下拉容器追加在 body 且 z-index（1051）低于弹窗（1070），弹窗内的下拉被遮挡无法点选。已全局提升至弹窗层之上，弹窗内外一致可用。

### 6. 弹窗表单提交的 CSRF 419 与双提交按钮

- DialogForm 通道加载的表单自动补 `_token` 隐藏域（模板本身不自带，裸用会被 CSRF 中间件静默拦截）；
- 弹窗表单统一由 layer 底部按钮驱动提交，表单自带提交/重置按钮自动隐藏，不再出现双提交按钮。

### 7. 嵌套弹窗层叠管理（bootstrap 驱动回退保障）

bootstrap 驱动（`modal_driver=bootstrap` 回退形态）下的孤儿 backdrop 清扫与 z-index 最高值递增补齐——即使切回旧驱动，嵌套弹窗关闭后的遮罩残留、点击失效也不再出现。
