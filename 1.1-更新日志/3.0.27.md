# 更新日志 v3.0.27（正式版）

- **发布版本**：v3.0.27（**正式版**，承接 v3.0.26）
- **发布日期**：2026-11-21
- **范围**：侧栏折叠状态持久化修复、top_side 折叠态悬停体验、hourPicker help 提示修复；**2.x 暂不发布**

---

## 一、修复：侧栏折叠状态刷新后丢失（汉堡按钮持久化）

**现象**：点击顶栏汉堡按钮折叠侧栏，刷新页面后侧栏恢复展开——折叠状态"存不住"。

**根因**：AdminLTE PushMenu 的原生持久化（localStorage）由 `enableRemember` 选项控制，该选项默认关闭且从未开启——汉堡点击一直是**纯客户端切换**，不写任何存储。侧栏折叠状态唯一持久化通道是布局设置面板的「侧边栏折叠」开关（保存到 `layout_config`，服务端按配置渲染 body class）；v3.0.26 为 top_side 模式恢复汉堡按钮后，用户自然改走汉堡通道，这条"无持久化"的路径随之暴露。

**修复**：汉堡折叠/展开时把 `sidebar_collapsed` 回存到 layout 配置——与面板开关收敛到**同一配置源**（服务端单一事实源），刷新时由服务端渲染还原。

- 与布局面板「侧边栏折叠」开关互相同步（两个入口，一个状态）；
- 仅桌面（≥992px）生效，移动端 AdminLTE 自动折叠不触发回存；
- pjax 导航持续有效；仅管理员角色生效（与布局配置权限一致）。

**实测**：折叠 → 刷新保留 ✓；展开 → 刷新保留 ✓；面板开关勾选态双向自动同步 ✓。

> 升级提示：本版为视图层修复，生产环境升级后如开启了视图缓存需 `php artisan view:clear`。

## 二、修复：top_side 折叠态悬停侧栏时面板标题恢复图标+文字

top_side_menu 模式下，侧栏折叠态的面板标题只留图标；此前鼠标悬停展开侧栏时标题仍保持图标-only 居中样式。现对齐 AdminLTE 子菜单的 hover 行为：悬停展开时标题恢复正常**图标+文字**。

## 三、修复：hourPicker 字段 `->help()` 提示不显示

hourPicker 移植时的视图漏了 help 区块，`->help('说明文字')` 不渲染。已补渲染 help-block，与其它字段行为一致。
