## 主要新增

### 1. 首页示例重做为「ERP 经营驾驶舱」
- 安装后首页（`admin:install` 生成的 HomeController）不再是功能演示页，而是一套可直接交付的**经营驾驶舱**：四张 ApexCharts 图表（销售趋势/渠道占比/品类构成/履约达成）+ 双 Swiper 轮播 Banner + 跑马灯公告 + 最新订单与库存预警卡片。
- 全部演示数据集中在新增的 `Dcat\Admin\Support\ErpDashboardData` 类，**接入真实业务只需替换这一个类的数据来源**（订单、库存、客户查询），页面组装代码一行不改：

```php
public function index(Content $content)
{
    $data = ErpDashboardData::make();   // 真实项目中替换为查询服务

    return $content
        ->header('ERP 经营驾驶舱')
        ->row(view('admin::dashboard.erp', [
            'data'    => $data,
            'charts'  => [...],          // 图表配置见 HomeController.stub
        ]));
}
```

### 2. HasMany 表格模式（useTable）重构：结构化表头
- 表格模式的行内字段样式统一收敛到 `applyTableStyle()`，模板行与数据行渲染完全一致；
- 表头变为结构化定义（label / help / width / class），字段的 `->help()` 自动**上收到表头**，以 ❓ 图标 + layer.tips 悬浮气泡展示，不再挤占单元格；
- 任意字段可用 `columnWidth()` 指定列宽，未指定时按字段类型给默认值（switch 70px、number 100px、select 150px、textarea 200px）并自动居中：

```php
$form->hasMany('items', '报名项目', function (Form\NestedForm $table) {
    $table->text('name', '项目名称');
    $table->decimal('price', '单价(元)')
        ->columnWidth('120px')          // 列宽渲染到表头 <th>
        ->help('个人=每人价；团体=每队价'); // help 上收表头
    $table->number('quota', '名额');      // 默认列宽 100px + 居中
    $table->switch('enabled', '启用');    // 默认列宽 70px + 居中
})->useTable();
```

- `Field` 基类新增 `columnWidth()` / `getHelp()` / `clearHelp()`；`Text` 提取 `DEFAULT_PREPEND` 常量支持识别默认图标；`Textarea` 支持识别默认 rows（表格内自动收敛为 2 行）。

### 3. Form Tab 刷新记忆（URL hash 恢复）
- 表单 Tab 自动 id 改为按「请求路径 + 表单类名」确定性生成，跨渲染稳定；配合 URL hash，**刷新页面后自动回到之前所在的 Tab**：

```php
// 无需额外代码，默认生效；需要语义化 hash 时可显式传 id
$form->tab('基本信息', function (Form $form) { ... }, $id = 'profile');
```

### 4. 双栏菜单第一栏细滚动条
- 左栏图标列表滚动条从浏览器默认宽度改为 4px 细滚动条，并补 `scrollbar-width: thin` 兼容 Firefox。

## 移动端适配（系统性修复）

### 5. 顶部导航栏单行 60px 布局
- 修复 <992px 时图标纵向堆叠、导航栏被撑高到 500px+、头像溢出屏幕的问题；图标行在 390px 视口内完整可见，更窄屏幕由页面级横向滚动兜底。

### 6. 导航栏下拉菜单定位修复
- 修复点击头像/通知时菜单错位到页面中间、顶部被裁切的问题；菜单恢复绝对定位、锚定触发图标下方右对齐、宽度以 `calc(100vw - 1rem)` 收敛。

### 7. layui-layer 弹层移动端全局适配
- ≤768px 下所有 layer 弹层（通知详情、表单弹窗、确认框等固定宽度弹层）自动收敛为左右各留 10px 全宽显示，内容区限高内部滚动；loading / tips / msg 小浮层不受影响。

### 8. 滚动定位补偿吸顶导航栏
- `html { scroll-padding-top: 70px }`：锚点跳转、`scrollIntoView` 等滚动定位自动停在导航栏下方，不再钻到导航栏下面。

## 修复

### 9. UEditor 层级与浮动工具栏
- 容器 `z-index: 999` 高于吸顶导航栏（997），滚动时盖住导航栏 → 新增配置项，默认已校准：

```php
// config/admin.php
'ueditor' => [
    'z_index'    => 990,  // 容器层级，低于导航栏 997；内部弹窗/菜单自动 +10 派生
    'top_offset' => 60,   // 浮动工具栏距视口顶部偏移，让出导航栏高度
],
```

### 10. UEditor UTF-8 内容净化修复
- 修复 `UeditorHtmlSanitizer` 处理含中文的内容时被按 ISO-8859-1 双重编码、入库乱码的问题（`loadHTML` 前置 XML 声明强制 UTF-8 解析）。

### 11. 其它
- 接口文档依赖切换为 `ycookies/apidoc`；
- `Textarea` 数组值 `json_encode` 补 `JSON_UNESCAPED_UNICODE`；
- README 以 3.x 为主版本重写（环境要求、安装命令、版本亮点）。
