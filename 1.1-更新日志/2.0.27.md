## 主要新增

### 1. Show 富文本字段自动识别渲染（richText）
- 后台同时存在 HTML 编辑器（`editor`，UEditor）与 Markdown 编辑器（`markdown`）时，详情页同一字段的内容来源可能两种都有。新增 `richText()` 预设，**自动识别内容格式并选择渲染方式**：

```php
// 详情页一行搞定，两种编辑器保存的内容都能正确预览
$show->field('content', '内容')->richText();
```

- 识别规则（启发式，有序命中）：
  - **HTML**：块级标签（`<p>`、`<div>`、`<table>` 等）开头，或包含 `</p>`、`<br`、`&nbsp;` 等 UEditor 指纹 → 原样渲染（等价 `unescape()`）；
  - **Markdown**：行首 `#` 标题、围栏代码块、列表/引用、`**粗体**`、`[链接](url)` 等特征 → 交给 Markdown 组件渲染；
  - **纯文本**：安全兜底按 Markdown 渲染（视觉不变）。
- 底层能力可单独使用（自定义页面、接口返回内容渲染等）：

```php
use Dcat\Admin\Support\ContentFormat;

ContentFormat::render($detail['docs_contents']); // 返回可直接嵌入的 HTML
ContentFormat::detect($content);                  // 返回 ContentFormat::HTML / ::MARKDOWN
```

> 混合内容（Markdown 内嵌 HTML 块）会识别为 HTML；确知格式时可用 `unescape()` 或 `Markdown::make()` 显式指定。

### 2. 新增内置字段：日期/日期时间区间选择器
- `dateRangePicker` / `datetimeRangePicker`：**一个输入框**内弹出日历拖选起止区间（daterangepicker，中文界面、支持时分秒），点「确定」才写回、点「清除」保留原值不丢数据；
- 提交时拆写为两个隐藏域按 start/end 两列存储，**存储结构、回显、查询与 `datetimeRange` / `dateRange` 完全一致**，老数据可无缝互换：

```php
$form->datetimeRangePicker('start_at', 'end_at', '活动时间');
$form->dateRangePicker('start_date', 'end_date', '活动日期');
// 等价存储：datetimeRange('start_at', 'end_at', ...) / dateRange(...)
```

- 纯日期版（`dateRangePicker`）回显时自动截断库存 datetime 的时间部分；
- 插件资源随包分发，新增 `@daterangepicker` 资源别名，无需额外安装：

```php
// 自定义组件中引用资源
\Dcat\Admin\Admin::js('@daterangepicker');
\Dcat\Admin\Admin::css('@daterangepicker');
```
