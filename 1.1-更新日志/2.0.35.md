## 修复

### 1. 异步表格行删除/批量删除后不跳转、表格原地重载

- **现象**：弹窗异步表格里点行「删除」并确认后，整页跳转到 `setResource` 指定的资源列表页，弹窗上下文丢失。
- **根因**：删除完成后 grid JS 携带 `data-redirect`（`setResource` 的资源路径或异步请求 URL）执行 `Dcat.reload(url)` 定向重载——带 url 的 reload 一直是跳转拦截链的透传分支。
- **修复**：document 捕获阶段记录最近一次点击是否在 `.async-table` 内（删除确认框 swal 中的点击延续上下文，**无时间窗**），命中时把带 url 的 reload 改写为该表格 `table:load` 原地重载。批量删除同样生效；非弹窗场景（展开行/独立异步表格）原地刷新，普通页面行为不变。

### 2. viewOnly 弹窗（弹窗查看）关闭遮罩残留，根治页面被挡住

- **现象**：弹窗查看详情页时**有时带遮罩层**，关闭后页面被遮罩挡住无法操作（环境相关：iframe-tabs 模式 layer 开到顶层窗口、多层开关循环累积时必现）。
- **根因**：viewOnly 的 × 关闭走 DialogForm cancel 分支只 `hide` 不 destroy——layer 节点与遮罩留在 DOM（顶层窗口场景遮罩盖住整页）。
- **修复**：
  - × 关闭改为 `_destroy`（layui close 连同遮罩一并移除）+ 延迟调用全局遮罩清扫；
  - 新增全局清扫 `window.__dcatSweepLayerShades`：移除「对应 layer 已关闭/隐藏」的残留遮罩（按 id 配对，不误伤活跃弹层），**兼容顶层窗口**，并在 `pjax:complete` 时一并执行——历史泄漏的遮罩一次切页即被清掉。

## 主要新增

### 3. 异步表格行操作自动适配：弹窗编辑 / 弹窗查看

弹窗异步表格里的整页编辑/查看会离开当前上下文且不可回退。现在**用户未自定义 `actions()` 时自动适配**：整页编辑/查看自动禁用，替换为**快捷编辑**（弹窗表单）与**弹窗查看**（DialogView，viewOnly 弹层加载详情页、`_dialog_form_` 最小化渲染无侧栏）。用户自定义 `actions()` 时尊重配置不替换。

### 4. 异步表格默认启用弹窗创建

`showCreateButton() + enableDialogCreate()` 两行**默认化**——异步表格自动带「新增」弹窗创建按钮，无需手写。用户显式 `$grid->disableCreateButton()` 时尊重配置。

### 5. 弹窗查看支持自定义弹层尺寸

详情内容较多时可通过函数设置窗口大小（对标原 `modal->xl()`）：

```php
// 方式一：网格级配置（异步表格自动适配透传）
$grid->dialogViewSize('xl');

// 方式二：actions 闭包内
$grid->actions(function (Grid\Displayers\Actions $actions) {
    $actions->dialogView('xl');
});
```

支持的值：预设 `'sm'`（600px×60%）/ `'lg'`（800px×80%）/ `'xl'`（1140px×90%）、自定义数组 `['800px', '600px']`、宽度字符串 `'80%'`；不设置用 `admin.dialog_form_area` 默认尺寸。

### 6. 新增网格级弹窗查看开关 `enableDialogView()`

页面级数据表格（非异步表格）也可开启弹窗查看，与 `enableDialogCreate()` 同款 API：

```php
$grid->enableDialogView();     // 行操作「查看」→ 弹层打开详情页，不离开当前页面
$grid->dialogViewSize('lg');   // 可选：尺寸
```
