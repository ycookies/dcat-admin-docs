- **发布版本**：v3.0.26（**正式版**，承接 v3.0.25）
- **发布日期**：2026-11-20
- **范围**：top_side_menu 第4态菜单（顶栏一级+左侧二级）、角色编辑页全新权限矩阵（双模式可回退）、grid 行删除作用域修复；**2.x 暂不发布**

## 一、top_side_menu：第 4 态菜单模式（本轮核心）

菜单布局新增第 4 态 `top_side_menu`——**顶栏一级纯切换 + 左侧二级面板**，层级菜单场景下兼顾横向一级导航与纵向二级展示：

```bash
# 配置切换（config/admin.php）
'menu_style' => 'top_side_menu',
```

**特性**：

- 顶栏一级：菜单一级项平铺在顶栏（navbar-left），纯切换链接不跳转；
- 左侧二级面板：点击一级项后，左侧面板按组渲染该组的全部二级菜单，CSS 控制显隐；
- 汉堡按钮保留，侧栏可折叠（折叠态面板标题只留图标），与默认模式折叠能力对齐；
- 数据统一走 `Menu::getMergedNodes()`（DB 菜单 + 代码 `add()` 动态节点合并），two_col 双栏模式同样受益；
- 激活推断服务端/前端同源：`pathname` 精确匹配 > localStorage 记忆 > 第一组，pjax 跳转后自动重算；
- 适配 iframe-tabs 壳页（collapse 放开 flex 收缩限制）；
- 顶栏/面板/双栏图标栏统一补 `fa fa-fw` 前缀，**兼容裸值图标**（如 `fa-font`）不再丢图标；
- 视觉细节：面板组标题 14px、顶栏滚动条细化 2px。

> 适用形态：层级菜单（一级多、二级多）才能体现「顶栏一级+左侧二级」效果；demo/flat 类扁平数据下顶栏会拥挤。top_side 与 iframe-tabs 组合未深度适配。

## 二、角色编辑页：全新权限矩阵（双模式可回退）

### 1. Blade 权限矩阵成为默认

角色编辑表单重写为**权限矩阵**视图：资源卡片化展示（名称/URI/描述）、按资源勾选操作、创建/更新时间收为字段区一行 muted 小字、底部操作按钮居中排列，视觉令牌统一 AdminLTE3/BS4 主题标准（只动样式令牌，不动布局）。

### 2. 单条配置双模式切换

```php
// config/admin.php —— 单条扁平配置，不搞多键段
'permission' => [
    'role_editor_form' => 'new',    // 默认：Blade 权限矩阵
    // 'role_editor_form' => 'legacy',  // 回退：经典 Dcat Form 树表单
],
```

> 切换后须 `php artisan config:clear`。旧版本（矩阵上线前）行为即 `legacy`。

### 3. 省略文本悬停看全文

权限矩阵中资源标题/URI 超长省略时，悬停用 **layer.tips** 显示全文（内嵌浏览器不渲染原生 title，layer 与后台弹窗同一体系）。

## 三、修复

- **grid 行删除整页嵌套进表格盒子**：普通 resource 页行删除后误将整页内容嵌套进表格盒子——原地重载逻辑限定异步上下文才生效；
- top_side/双栏菜单图标栏兼容裸值图标（补 `fa fa-fw` 前缀，与 menu-item/sub-menu 对齐）。

## 四、升级注意

```bash
composer require dcat-plus/laravel-admin:^3.0
php artisan config:clear   # 如需切换 role_editor_form / menu_style 配置
```

本版无静态资源文件变更；`top_side_menu` 为纯增量第 4 态，现有 `menu_style` 配置不受影响。
