## 一、Modal 弹窗体系全面重构（内部测试重点）

### 1. BS4 modal 全面迁移 layui-layer（方案 A 治本）

`Widgets\Modal` 重写为 layer 承载，类签名冻结、现有代码零改动。Bootstrap 4 modal 官方不支持多实例叠加，嵌套弹窗 z-index 固定 / fade 回调卡死 / dismiss 冒泡 / onShow 误触 / stacking context / FilterButton 拦截**六大死因根除**。兼容问题可 `config/admin.php` 切回：`'layout' => ['modal_driver' => 'bootstrap']`。

### 2. 按内容类型三通道分流

| 内容类型 | 通道 | 特性 |
|---|---|---|
| LazyRenderable（异步表单） | DialogForm | `_dialog_form_` 最小化渲染、layer 底部提交 |
| LazyGrid（异步表格） | DialogForm + AsyncTable | 分页/排序/搜索/删除弹窗内原地完成 |
| **同步内容（HTML/组件/工具表单）** | 原生 layer | 内容随页面渲染、高度自适应、关闭归位可重开 |

同步通道元素身份不变（弹窗内交互跨开关延续）、`onShow/onShown/onHide/onHidden` 事件桥完整支持、`sm/lg/xl` 尺寸映射、footer 底部区。

### 3. 保存行为按 JsonResponse 指令分发

弹窗表单提交成功后完整尊重服务端指令，与整页表单语义对齐：

| 服务端写法 | 弹窗内行为 |
|---|---|
| `->success('msg')` | toast + 关弹窗，**不刷新** |
| `->success('msg')->refresh()` | toast + **整页重载** |
| `->download($url)` | toast + 新窗口下载 |
| `->location($url)` / `->redirect($url)` | toast + 整页跳转 |
| `->script($js)` | toast + 执行 JS |
| `->error('msg')` | 错误提示，弹窗保留 |

### 4. 提示形态全量支持

`alert()`（SweetAlert）/ `detail()`（弹窗正文）/ `timeout()`（toast 时长）/ `info()/warning()`（toast 类型）在弹窗内全部生效。

### 5. 同步工具表单（Widgets\Form + handle）弹窗支持

`Modal::make()->body(ToolForm::make())` 同款模式：提交自动走 `dcat-api/form` 端点分发（无需注册路由），**成功后自动关闭所在弹层**再按 then 指令动作；失败弹窗保留。

### 6. 异步表格弹窗全链路

行删除/批量删除后不跳转原地重载；行操作自动适配（弹窗编辑/弹窗查看）；默认启用弹窗创建；`enableDialogView()` 网格级弹窗查看 + `dialogViewSize()` 尺寸配置；viewOnly 遮罩残留根治。

### 7. 修复

- select2 下拉在弹窗内无法选择（z-index 低于弹窗）
- 弹窗表单 CSRF 419（DialogForm 通道自动补 `_token`）与双提交按钮
- 事件桥 `onHidden` 被静默丢弃（`'hidden'` 不以 `'hide'` 开头的前缀匹配 bug）
- 工具表单成功自动关层首版钩子误用 `Dcat.Form.submitted`（不存在的静态方法）导致同页 handler 注册中断——已改包装 `handleJsonResponse` 方案

## 二、安全升级：jQuery 3.4.1 → 3.7.1

修复 **CVE-2020-11022 / CVE-2020-11023**（`$.html()` XSS）。`vendors.min.js` 由 packer 混淆重组为明文分段（jQuery 3.7.1 + Popper + BS4 JS + Hammer + perfect-scrollbar 1.4.0），并清理两个零引用历史库（screenfull、es6-promise）。

> ⚠️ **升级注意**：静态资源有变更，执行 `php artisan admin:publish --assets --force`（勿裸 `--force`，会覆盖 config）并强制刷新浏览器。
