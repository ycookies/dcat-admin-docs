## 一、新字段：hourPicker 时刻选择器（自 fithub 扩展移植）

点击弹层、按**凌晨 / 上午 / 下午 / 晚上**分组平铺时刻小按钮（非滚轮），中文界面零配置。

- **值 =「HH:MM」**，与 `time` 字段同格式，后端零改动；选中回填触发框并高亮按钮
- 已有值（default / 编辑回显）渲染时即高亮；支持清空（存空字符串）
- 链式配置：`->step(N)` 档位间隔（默认 60 整小时，可选 10/15/30 等须能整除 60）、`->hideSmallHours()` 隐藏凌晨组（00:00~05:59 不进候选）、`->placeholder()` 空态文案
- 注册进 `Form::$availableFields` + `@method` 注解；`Widgets\Form` 经 `Form::extensions()` 自动复用
- 原版硬编码业务文案「选时间（留空=不排）」已改为中性默认「选择时间」

```php
$form->hourPicker('open_time', '开门时间')->default('09:00')->step(30);
```

## 二、按钮 loading 统一三点动画（修复按钮消失与布局塌陷）

**现象**：`Modal::make()->button(...)` 的触发按钮点击加载时，**整个按钮消失**、只剩一个几乎看不见的单点动画，弹窗打开后才恢复原样——布局塌陷跳动；而表格「弹窗新建」（enableDialogCreate）一直是正常的「按钮中间三点加载动画」。同为 DialogForm 引擎，表现割裂。

**根因**：Modal 触发按钮被包了一层无 `.btn` 类的外壳（`.dcat-wmodal-toggle`），loading 施加在外壳上；`buttonLoading` 靠 `hasClass('btn')` 判定动画形态，外壳判定失败 → 降级单点动画，且替换内容时真实按钮整体被挪进隐藏 div。

**修复**（`$.fn.buttonLoading` 底层根治，所有调用方受益）：

1. **宿主下钻**：自身无按钮类时自动定位内部第一个真实按钮——三点脉动动画落在按钮中间、按钮盒保留，与 enableDialogCreate 原生表现完全一致；
2. **纯文本追加模式**：触发器内部无按钮时，原内容一字不动、仅末尾追加小号 spinner，加载完摘除——不再隐藏/替换任何已有内容，零布局塌陷；
3. 表单提交、Pjax、快捷编辑等既有调用行为不变；加载中防重入。

实测：异步表格 / 异步表单 / 弹窗提交按钮 / Form::dialog 原生按钮 / 同步通道全链路，桌面（1280px）+ 移动端（390px）双视口通过。

## 三、login-plus 登录页移动端适配

- html 字号 `min(28vw, 128px)`：3.125rem 登录框 ≈87.5vw，平板不过大
- 表单由贴右改为**水平居中**，去掉 `min-width:768px` 强制横向滚动
- 背景图移动端改 cover 裁切，避免竖屏拉伸失真
- 输入/按钮加高（≥38px）触控友好；输入框字号 ≥16px 防 iOS 聚焦自动放大

> ⚠ 旧版 `login.blade.php` 登录页本轮未适配，仍建议使用 login-plus。
