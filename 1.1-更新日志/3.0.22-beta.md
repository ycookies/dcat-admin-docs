# 更新日志 v3.0.22-beta（内部测试版）

- **发布版本**：v3.0.22-beta（**内部测试版**，承接 v3.0.21-beta）
- **发布日期**：2026-11-17
- **范围**：弹窗关闭即销毁语义落地、三条弹窗链路统一配置 `admin.layout.dialog`、遮罩根源修复及若干表单修复；**2.x 暂不发布**

---

## 一、弹窗生命周期：关闭即销毁

弹窗关闭后页面零残留——层壳、内容 DOM、遮罩全部真销毁，彻底告别"关了还在"的幽灵层。

### 1. 同步内容弹窗改为销毁式

同步通道弹窗关闭即销毁，不再以 template clone 方式复用 DOM，页面零 DOM 残留。

### 2. DialogForm 通道关闭改为真销毁

`DialogForm`（弹窗创建/快捷编辑）通道关闭即真销毁层壳/内容/遮罩；`forceRefresh` 原生配置**全局默认 true**——每次打开都重新拉取最新内容，移除旧 `keepAlive` 概念。

### 3. 残留遮罩自动清扫守护

兜底守护：层隐藏/移除即清扫其遮罩，任何异常路径都不再留下打不开页面的"黑罩子"。

---

## 二、三条弹窗链路统一配置：admin.layout.dialog

`Modal`（同步内容弹窗）、`DialogForm`（表单弹窗）、弹窗详情页三条链路的弹窗配置统一收敛到 `admin.layout.dialog` **单一事实源**，一处配置全局生效：

```php
// config/admin.php
'layout' => [
    'dialog' => [
        // 全局弹窗默认配置（三条链路共用）
    ],
],
```

> 配置变更后需 `php artisan admin:publish --force` 同步配置文件。

---

## 三、修复

### 1. 遮罩重现根除：弹窗详情响应剔除 layer.js（本轮核心修复）

layer.js 是实例化全局单例的资产，随弹窗详情响应重复执行会**重建实例**（index 起点跳到 1e5 量级）并丢失 `layer.config({shade:false})` 全局配置，导致此后所有弹窗带上默认遮罩。已在弹窗详情响应的 Content composing 阶段从 baseJs 中剔除 layer.js，其余静态资源保留（详情页组件依赖）。

> 识别特征：遮罩出现且控制台 `layer.index` 跳到 100000 量级，即为 layer.js 被重复执行重建了实例。

### 2. size(string) 自定义尺寸值被丢弃

`Modal::size('800px')` 传入字符串自定义尺寸时，layerWidth 只认档位键（sm/lg/xl）导致值被丢弃；现已透传自定义值。

### 3. 异步弹窗打开后同步弹窗高度失效

50vh 样式全局注入造成污染，异步弹窗打开后同步弹窗高度失效，已修复。

## 四、新增

### 1. draggableList 表单类型

`Form` 新增 `draggableList` 字段类型注册，可与 `list` 字段并行使用。

### 2. SkuField 默认补齐 extra_column 变量

未调用 `addColumn()` 时模板不再因缺 `extra_column` 变量报错，默认补齐空数组。
