## 一、弹层高度语义重构（本轮核心）

### 1. 显式指定高度 → 恒定不变

`sm()/lg()/xl()` 档位、`Form::dialog` 的 dimensions、配置 `dialog_form_area`——**开屏多大就多大，绝不缩放**。修正上一版"显式尺寸被内容收缩"的违反直觉行为：

```php
Modal::make()->xl()->title('大弹窗')->body($content);
// xl 恒定 1140px × 90%，内容少也不会缩
```

### 2. 未指定尺寸 → 内容自适应，开屏即终态

不调用尺寸方法的弹层直接以 `height: auto` 打开——两条通道（DialogForm 异步、原生 layer 同步）都是**内容就绪后才开层**，开屏瞬间即为终态高度，**全程无二次调整、无动画感**；内容超高 90% 视口时封顶一次并转内容区内部滚动（瞬时跳变），内容回落自动还原 auto。

```php
Modal::make()->title('自适应弹窗')->body($smallContent); // 高度贴合内容
```

> 超高封顶守护覆盖全部 page 型 layer（含快捷编辑/弹窗创建等 DialogForm 通道），显式尺寸弹层不受影响。

### 3. 根因修复：layer 开场动画半程定格

`layer-bounceIn` 开场动画的 `fill-mode: both` 会在弹层隐藏/中断时把**半程 scale(0.5) 永久定格**——表现为弹层渲染只有一半高度、改 height 内联样式也无效（动画优先级高于内联）。已全局禁用 layer 动画与过渡，同时移除内容区 `min-height:50vh`（内容少时下半截空白的直接原因）。
