## 一、Modal 弹窗体系全面重构（本版核心）

### 1. BS4 modal 全面迁移 layui-layer 承载（方案 A 治本）

`Widgets\Modal` 重写为 layer 承载，**类签名冻结、现有代码零改动**。Bootstrap 4 modal 官方不支持多实例叠加，以下**六大死因根除**：

- 嵌套弹窗 z-index 固定
- fade 回调卡死
- dismiss 事件冒泡
- onShow 误触
- stacking context 隔离
- FilterButton 拦截

兼容问题可回退驱动：`config/admin.php` → `'layout' => ['modal_driver' => 'bootstrap']`。

### 2. 按内容类型三通道分流

| 内容类型 | 通道 | 特性 |
|---|---|---|
| LazyRenderable（异步表单） | DialogForm | `_dialog_form_` 最小化渲染、layer 底部提交 |
| LazyGrid（异步表格） | DialogForm + AsyncTable | 分页/排序/搜索/删除弹窗内原地完成 |
| 同步内容（HTML/组件/工具表单） | 原生 layer | 内容随页面渲染、高度自适应、关闭归位可重开 |

同步通道**元素身份不变**（弹窗内交互跨开关延续）、`onShow/onShown/onHide/onHidden` 事件桥完整支持、`sm/lg/xl` 尺寸映射、footer 底部区。

### 3. 三条弹窗链路统一配置：admin.layout.dialog

`Modal`（同步内容弹窗）、`DialogForm`（表单弹窗）、弹窗详情页三条链路的弹窗配置统一收敛到 `admin.layout.dialog` **单一事实源**，一处配置全局生效：

```php
// config/admin.php
'layout' => [
    'dialog' => [
        // 全局弹窗默认配置（三条链路共用）
    ],
],
```

### 4. 弹层高度语义：显式恒定 + 未指定 auto 自适应

- **显式指定高度 → 恒定不变**：`sm()/lg()/xl()` 档位、`Form::dialog` 的 dimensions、配置 `dialog_form_area`——开屏多大就多大，绝不缩放；
- **未指定尺寸 → 内容自适应**：`height: auto` 开屏即终态，内容超高 90% 视口时封顶一次并转内容区内部滚动，内容回落自动还原；
- 根因修复：`layer-bounceIn` 开场动画 `fill-mode: both` 在弹层隐藏/中断时把半程 scale(0.5) 永久定格——已全局禁用 layer 动画与过渡。

### 5. 关闭即销毁：层壳/内容/遮罩零残留

- 同步通道：纯静态内容 template clone 销毁式；**含表单的同步内容自动切容器模式**——容器随页面渲染（脚本绑定成功）、点击整体搬入弹层（元素身份不变）、关闭 `.detach()` 摘出 DOM（页面零残留且事件绑定/输入值在内存延续，重开即恢复）；
- DialogForm 通道：关闭真销毁，`forceRefresh` 全局默认 true——每次打开重新拉取最新内容；
- 残留遮罩自动清扫守护：层隐藏/移除即清其遮罩，异常路径不再留"黑罩子"；
- 由 `admin.layout.dialog` 的 `destroy_on_close` 统一派生（false 回退 BS4 旧归位语义）。

### 6. 弹窗表单保存行为：按 JsonResponse 指令分发

弹窗表单提交成功后完整尊重服务端指令，与整页表单语义对齐；提示形态全量支持（`alert()/detail()/timeout()/info()/warning()`）：

| 服务端写法 | 弹窗内行为 |
|---|---|
| `->success('msg')` | toast + 关弹窗，不刷新 |
| `->success('msg')->refresh()` | toast + 整页重载 |
| `->download($url)` | toast + 新窗口下载 |
| `->location($url)` / `->redirect($url)` | toast + 整页跳转 |
| `->script($js)` | toast + 执行 JS |
| `->error('msg')` | 错误提示，弹窗保留 |

同步工具表单（`Widgets\Form` + handle）弹窗支持：提交自动走 `dcat-api/form` 端点分发（无需注册路由），成功后自动关闭所在弹层再按 then 指令动作，失败弹窗保留。

## 二、遮罩重现根除：弹窗详情响应剔除 layer.js

layer.js 是实例化全局单例的资产，随弹窗详情响应重复执行会**重建实例**（index 起点跳到 1e5 量级）并丢失 `layer.config({shade:false})` 全局配置，导致此后所有弹窗带上默认遮罩。已在弹窗详情响应的 Content composing 阶段从 baseJs 中剔除。

> 识别特征：遮罩出现且控制台 `layer.index` 跳到 100000 量级，即为 layer.js 被重复执行重建了实例。升级后强刷浏览器 index 归零。

## 三、其他修复

- `Modal::size('600px')` 字符串自定义尺寸被丢弃（layerWidth 只认档位键）——符合 px/%/vw/vh 格式直接透传
- 异步弹窗打开后同步弹窗高度失效（50vh 样式全局注入污染）
- select2 下拉在弹窗内无法选择（z-index 低于弹窗）
- 弹窗表单 CSRF 419（DialogForm 通道自动补 `_token`）与双提交按钮
- 事件桥 `onHidden` 被静默丢弃（`'hidden'` 不以 `'hide'` 开头的前缀匹配 bug）
- 工具表单提交 toast 弹两次（框架响应链尾部已统一分发，savedScript 恢复为空钩子）
- 内置 `zgldh/qiniu-laravel-storage` 的 Flysystem v3 兼容补丁（未安装该包零开销）

## 四、新增

- **draggableList 表单类型**：可拖拽列表（sortable/nestable），SKU 规格属性场景内置"新增/管理规格" xl 弹窗

## 五、安全升级：jQuery 3.4.1 → 3.7.1

修复 **CVE-2020-11022 / CVE-2020-11023**（`$.html()` XSS）。`vendors.min.js` 由 packer 混淆重组为明文分段（jQuery 3.7.1 + Popper + BS4 JS + Hammer + perfect-scrollbar 1.4.0），并清理两个零引用历史库（screenfull、es6-promise）。
